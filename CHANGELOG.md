# Changelog

All notable project changes are recorded here.

## 0.2.0 — In development

- Added bounded concurrent runs and optional warm-up requests.
- Split HTTP transport and report aggregation into dedicated modules.
- Added request validation, HTTPS enforcement for non-loopback endpoints, response-size limits, and sanitized errors.
- Added report environment/workload metadata and JSON schema documentation.
- Added product brief, architecture, benchmark methodology, provider support policy, roadmap, and contributor/security guidance.
- Added GitHub issue templates, pull-request checklist, and package/CLI smoke workflow.
- Reports omit prompts, completions, credentials, and provider response bodies.
